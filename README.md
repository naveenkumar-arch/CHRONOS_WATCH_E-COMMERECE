# 🕰️ CHRONOS Luxury Timepieces

A premium, modern e-commerce web application built for a luxury watch brand. 

## ✨ Features

- **Modern Tech Stack**: Built with React, Vite, and Tailwind CSS.
- **Dynamic Catalog**: A rich collection of Dress, Diver, Chronograph, and Luxury watches.
- **Client-Side Routing**: Fast, seamless page transitions powered by React Router.
- **Authentication**: User login, profile management, and state persistence.
- **Checkout Flow**: Interactive cart management with a multi-step simulated payment gateway.
- **Responsive Design**: Flawless interface across desktop, tablet, and mobile devices.

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the development server:**
   ```bash
   npm run dev
   ```
3. Open your browser and navigate to `http://localhost:5173`.

## 📁 Project Structure

- `src/components`: UI components like Navbar, Footer, and Modals.
- `src/context`: React Context providers for global state (Auth, Cart).
- `src/pages`: Dedicated views for Home, Our Story, Boutiques, etc.
- `src/data`: The comprehensive product catalog.
